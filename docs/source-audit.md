## Outras ferramentas encontradas

- [UnityPy](https://github.com/K0lb3/UnityPy): MIT; exporta texturas/sprites e permite enumerar objetos e caminhos internos. É candidata natural para uma extensão Python opcional. O projeto alerta para alterações de API e falhas possíveis no leitor nativo de typetree; executar futuramente em processo isolado com limites, versão fixada e saída separada. Não foi instalada ou testada aqui.
- [AssetRipper](https://github.com/AssetRipper/AssetRipper): GPL-3.0; analisa arquivos Unity e exporta recursos para formatos Unity. A faixa de versões declarada inclui engines antigas, mas isso não comprova as particularidades de PoE1. Alternativa de investigação externa; não incorporada.

## O que se sabe sobre mapas e marcadores

As coordenadas visíveis no índice Itemaps constituem evidência de dados estruturáveis, mas não estabelecem origem, escala, transformação, plano Unity, unidade de distância nem correspondência de cada marcador com um objeto original. Categorias de site também são insuficientes: “Loot” não determina se há baú, cadáver ou item solto; uma saída sem destino não é uma transição funcional.

Não foi possível inspecionar HTML bruto ou recursos JavaScript pelo shell: a tentativa de leitura pública por `urllib` falhou por DNS (`getaddrinfo failed`). O leitor web forneceu o texto HTML indexado. Portanto não se registram nomes fictícios de campos embutidos, endpoints deduzidos ou um scraper como concluído.

Texturas exportáveis não estabelecem a composição final dos cenários. Antes de reconstruir, é necessário inventariar materiais, malhas/UV, transformações, câmeras, ordem de camadas e vínculos de cena da instalação local. Na falta desses dados, o mapa permanece pendente e recebe calibração manual. Não houve reconstrução de mapa comercial nesta execução.

## Coleta implementada nesta base

`tools/import-public.mjs` recebe **um formato JSON próprio já normalizado**, documentado em [public-import.md](public-import.md). Não coleta a página Itemaps, não interpreta HTML/JavaScript e não presume seu schema interno. A separação é intencional: a aquisição específica por fonte exige estrutura e condições verificadas. Dados não reconhecidos são recusados; desconhecimento de categoria permanece explícito. Todo resultado é referência local atribuída e não redistribuível por padrão.
